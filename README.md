# Full Stack Q&A Platform — Frontend

A modern Question and Answer platform frontend built with **React**, connecting to a Django REST Framework backend. Users can ask questions, provide answers, and interact with the community in real time.

## 🚀 New Features
- **Google OAuth Login**: Users can continue with Google for authentication
- **Password Reset Flow**: Request password reset via email, securely update password
- **Discussion Rooms**: Real-time chat per question
- **Engagement System**: Likes/dislikes for questions and answers
- **Notifications**: Activity notifications fetched from backend
- **Responsive & Dark Mode Friendly Design**

## 🛠️ Tech Stack
- React, React Router, Axios, Vite
